## Documentation

Every graph node is a container for context. You can attach documentation to any node — project, folder, file, class, or function — and keep it exactly where it is used.

### Why it helps

* Centralizes knowledge next to the code that needs it
* Reduces context‑switching and hunting through folders or wikis
* Improves onboarding and code reviews with in‑place explanations
* Makes LLM access cheaper and more accurate by scoping docs to the node
