# vn-logger


`vn-logger` is a Python library that decorates your functions to emit structured, context‑aware logs and ships them to a JSON‑RPC endpoint. Each event is tagged with its call chain and parent/child relationships, so logs form a navigable execution tree instead of flat lines. This lets you trace requests end‑to‑end, pinpoint where an error occurred, and understand cause‑and‑effect without stitching logs together by hand.

## Usage

### 1. Configure the Logger

First, you need to configure the logger with your JSON-RPC endpoint and a project ID. This should be done once when your application starts.

```python
from vn_logger import configure_logger

configure_logger("http://localhost:8000/jsonrpc", "your-project-id")
```

### 2. Use the `context_logger` Decorator

Apply the `context_logger` decorator to any function you want to monitor. You must copy a unique `function_id` for each decorated function generated by the ide, when parsing it will apeare as `""" ID: {id} """` . 

```python
from vn_logger import context_logger

@context_logger(function_id="some-unique-function-id")
def my_function(arg1, arg2):
    """ ID: {some-unique-function-id} """
    # Your function logic here
    return "result"

my_function("a", "b")
```

The logger will automatically capture:
- Function entry and exit.
- Arguments and return values.
- Execution duration.
- Unhandled exceptions.
- A `chain_id` to trace a sequence of calls.
- The `parent_function_id` to build a call hierarchy.
